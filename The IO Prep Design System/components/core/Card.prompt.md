Generic content container — course cards, testimonial cards, dashboard panels.

```jsx
<Card><h3>IB English A&L</h3><p>24 lessons</p></Card>
```

Flat white/cream surface, 1px hairline border, 3px radius, restrained shadow. Set `padded={false}` to control inner spacing yourself (e.g. when a card contains a full-bleed image).
