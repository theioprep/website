Primary call-to-action button in four variants, used for enrolment/purchase actions and secondary navigation.

```jsx
<Button variant="primary" size="md" onClick={() => enrol()}>Enrol now</Button>
<Button variant="secondary">View syllabus</Button>
```

Variants: `primary` (solid Oxford blue), `secondary` (outlined), `gold` (accent, sparing — checkout/upsell only), `ghost` (text-only). Sizes: `sm`, `md`, `lg`. Set `disabled` to dim to 45% opacity.
